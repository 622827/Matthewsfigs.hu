  1. Nyisd meg: github.com → új Fine-grained token
  2. Név: csomagok, lejárat: amit szeretnél (pl. 1 év).
  3. Repository access: Only select repositories → Matthewsfigs.hu
  4. Permissions → Repository → Actions: Read and write és Contents: Read-only (mást ne adj).
